# Optavius website

Next.js (App Router), React and TypeScript. Layout and visual system reproduced from a Sierra-style reference; all content,
media and mockups are Optavius' own.

## Run

```bash
npm install
npm run build && npm start      # http://localhost:3000
```

## Structure

- `app/[[...slug]]/page.tsx` renders every page for every language from one route. English lives at `/`, Dutch under `/nl`,
  German under `/de`. `generateStaticParams` lists all 117 pages.
- `content/en.ts`, `content/nl.ts`, `content/de.ts` hold all copy and page data (typed by `content/types.ts`);
  `content/shared.ts` holds asset paths and constants (phone number, email, Calendly, logos, videos);
  `content/articles.json` holds the resource articles in three languages.
- `components/site/Pages.tsx` composes the pages from the templates in `components/tpl/` (hero, feature split, quote band,
  tiles, proof points, steps, video quotes, pricing, stories, demo player, form, prose).
- `components/home/` keeps the home-page specials (video hero with call bubbles, bento cards, "Meet the console" scroll section).
- `components/mockups/` holds the product mockups (console, agents, phone scenes, the particle eye in `Eye.tsx`).
- `app/styles/site.css` is the compiled design-system stylesheet; `app/styles/mockups.css` is generated by
  `node scripts-build-mockups-css.mjs` (run it whenever component classes change, then `npm run build`).
- `public/optavius/` holds logos, photos and the generated media (`gen/`: hero clips, specialty clips, customer portraits and
  talking-head clips).

## Things to supply

- Demo audio: put the sample calls at `public/optavius/demo-call-en.mp3`, `demo-call-nl.mp3` and `demo-call-de.mp3`. The
  home-page player picks them up automatically and scrolls the transcript with the audio (timings in `home.demo.transcript`
  in each content file).
- Customer portraits in `public/optavius/gen/` (`feike.jpg`, `ahmed.jpg`, `tom.jpg`) are the supplied photos.
- The sign-in link points to `https://app.optavius.com`.

## Tooling

`tooling/` contains the scripts used to generate media (`gen-optavius.js`, fal.ai), screenshot pages (`opshots.js`) and sweep
every page for errors, broken images and stray brand names (`opsweep.js`).

## Deployment

The site is exported as static HTML and published with GitHub Actions to GitHub Pages
(`.github/workflows/pages.yml`). Every push to `main` redeploys https://ppleeuw.github.io/optavius/.

- `NEXT_PUBLIC_BASE_PATH` is the folder the site lives under (`/optavius` on GitHub Pages, empty on a custom domain).
- `NEXT_PUBLIC_SITE_URL` is the public origin used for the sitemap, social images and structured data.

When www.optavius.com points at GitHub Pages, set a custom domain in the repository's Pages settings and
change both variables in the workflow to `""` and `https://www.optavius.com`.
